<div dir="rtl">

مكتوب من الصفر بلغة Rust، وواجهته مرسومة على كرت الشاشة مباشرة بـ eframe و egui بلا متصفّح مدمج، ولهذا حجم الملف عشرة ميجابايت لا مئتين. والبناء بأمر واحد:

</div>

```bash
cargo build --release
```

<div dir="rtl">

الناتج ملف واحد في `target/release/badeel.exe` بلا مثبِّت وبلا صلاحيات مدير. وصفحة **[داخل بديل](https://ryanathlawi.github.io/badeel-site/#/inside)** تشرح كل ما يفعله البرنامج على جهازك من أول خطوة إلى آخر خطوة، وأي ملف يقرأه أو يبدّله في كل منصّة، وما الذي لا يفعله أبدًا.

<sub>

**badeel** — a game account switcher for seven platforms on Windows, written in Rust.
Switch in one click with no password typing; every session is stored encrypted under a key bound to your Windows account and this machine alone, and every step of a switch has a way back.
No servers, no accounts, no tracking. [Website](https://ryanathlawi.github.io/badeel-site/?lang=en) · [How it works](https://ryanathlawi.github.io/badeel-site/?lang=en#/inside) · [Releases](../../releases) · GPL-3.0

أسماء وشعارات المنصّات علامات تجارية لأصحابها، وبديل غير تابع لأي منها.

</sub>
